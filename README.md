# Brian's Stag Do — Liverpool

Itinerary site for Brian's stag do in Liverpool, Wed 9th–Sun 13th, 16 lads.

**Live site:** https://joshpester.github.io/stag-do-liverpool/

## Editing

It's a single static page — `index.html`. To make a change:

```bash
git pull
# edit index.html
git add index.html
git commit -m "describe the change"
git push
```

GitHub Pages rebuilds automatically within a minute of a push to `master`.

Background/planning notes live in the [Stag Planning Google Doc](https://docs.google.com/document/d/1ShG7b66AmMa0THDTVb373a5M-De-ZE2HHtoLxg0fYgs/edit).
